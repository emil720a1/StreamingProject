# SQL Practice

This directory contains SQL queries used for learning and documenting
the StreamingProject database.

## Files

- `01-active-streams.sql` — selects active streams;
- `02-streams-with-users.sql` — demonstrates user-stream joins;
- `03-stream-participants.sql` — demonstrates many-to-many relationships.

These files are educational examples.
Production database access is implemented through Entity Framework Core repositories.
